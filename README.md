# 🍎 Fruit & Vegetable Market

A full-stack e-commerce web application for buying fresh fruits and vegetables online. Built with the **MERN Stack** to provide a smooth shopping experience with a responsive user interface.

## 🚀 Features

- 🥦 Browse fresh fruits and vegetables
- 🔍 Explore products with images, prices, and descriptions
- 🛒 Add products to the shopping cart
- 📱 Responsive design for desktop and mobile devices
- ⚡ Dynamic product data using REST APIs
- 🔧 Organized frontend and backend architecture

## 🛠️ Tech Stack

**Frontend**
- React.js
- JavaScript
- HTML5
- CSS3

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/VaibhavSain/Fruit-And-Vegetable-Shop-Using-Mern.git
cd Fruit-And-Vegetable-Shop-Using-Mern
```

### 2. Install dependencies

Navigate to the frontend and backend directories and install their dependencies.

```bash
cd client
npm install
```

```bash
cd ../server
npm install
```

### 3. Configure environment variables

Create a `.env` file in the backend directory.

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

Replace the database placeholder with your MongoDB connection string.

### 4. Run the application

Start the backend:

```bash
cd server
npm run dev
```

Start the frontend in another terminal:

```bash
cd client
npm start
```

Use the frontend URL displayed in your terminal to open the application.

*Note: Commands may differ depending on your package scripts and whether you use Vite or Create React App.*
